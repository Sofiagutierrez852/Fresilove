
# 🍓 Fresilove

### Un toque dulce en cada momento

Fresilove es una aplicación web creada para un emprendimiento de fresas con crema. Su objetivo es ofrecer a los clientes una experiencia sencilla, agradable y personalizada para conocer los productos y realizar sus pedidos.

## 🌸 Características principales

- Página de inicio con presentación del emprendimiento.
- Catálogo de productos.
- Personalización de pedidos.
- Selección de toppings y complementos.
- Registro de pedidos mediante Supabase.
- Contacto y comunicación por WhatsApp.
- Recomendador de productos.
- Panel de administración para consultar y actualizar pedidos.
- Inicio y cierre de sesión para el administrador.
- Diseño adaptable a dispositivos móviles y computadores.

## 🛠️ Tecnologías utilizadas

- HTML5: estructura de la aplicación.
- CSS3: diseño y estilos visuales.
- JavaScript: funcionalidades e interactividad.
- Supabase: base de datos y autenticación.
- Git y GitHub: control de versiones y almacenamiento del código.
- GitHub Pages: publicación del sitio web.

## 👩‍💻 Panel de administración

El administrador puede iniciar sesión para consultar los pedidos registrados y actualizar su estado.

## 🎯 Objetivo del proyecto

Desarrollar una aplicación web funcional que facilite la presentación de productos, la personalización de pedidos y la gestión de un emprendimiento de fresas con crema.
