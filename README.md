# 🍓 Fresilove

### Un toque dulce en cada momento 💗

Fresilove es una aplicación web desarrollada para un emprendimiento de fresas con crema. Su propósito es brindar a los clientes una experiencia sencilla, agradable e interactiva para conocer los productos, personalizar sus pedidos y descubrir combinaciones de sabores.

## 🌸 Características principales

- Página de inicio con presentación del emprendimiento.
- Catálogo de productos con fotografías y precios.
- Personalización de pedidos.
- Selección de toppings y complementos.
- Cálculo automático del precio del pedido.
- Registro de pedidos mediante Supabase.
- Formulario de contacto y comunicación por WhatsApp.
- Recomendador de productos según los gustos y preferencias del cliente.
- Panel de administración para consultar y actualizar pedidos.
- Inicio y cierre de sesión para el administrador.
- Diseño adaptable a computadores y dispositivos móviles.

## 🛠️ Tecnologías utilizadas

- **HTML5:** estructura de la aplicación.
- **CSS3:** diseño visual y adaptación a diferentes pantallas.
- **JavaScript:** funcionalidades e interactividad.
- **Supabase:** base de datos y autenticación.
- **Git:** control de versiones.
- **GitHub:** almacenamiento y gestión del código.
- **GitHub Pages:** publicación de la aplicación web.

## 👩‍💻 Panel de administración

El administrador puede iniciar sesión para acceder a un espacio privado donde puede consultar los pedidos registrados y actualizar su estado.

## 🍓 Recomendador de productos

La aplicación cuenta con un recomendador que utiliza las preferencias y restricciones indicadas por el cliente para sugerir combinaciones de fresas con crema y toppings.

## 🎯 Objetivo del proyecto

Desarrollar una aplicación web funcional que facilite la presentación de productos, la personalización de pedidos y la gestión de un emprendimiento de fresas con crema, integrando herramientas tecnológicas para mejorar la experiencia del cliente.
